# Searching

This section contains searching algorithms implemented
in C++ with a focus on understanding their logic,
efficiency, and applications.

## 📚 Algorithms

| Algorithm | Approach | Time | Space |
|-----------|----------|------|-------|
| Linear Search | Sequential Search | O(n) | O(1) |
| Binary Search | Divide and Conquer | O(log n) | O(1) |

## 🧠 Concepts Covered

- Array Traversal
- Linear Search
- Binary Search
- Sorted Arrays
- Divide and Conquer
- Time and Space Complexity

## 💻 Language

- C++

## 🎯 Goal

The goal of this section is to understand different
searching techniques and learn when to use each one
based on their time complexity and requirements.
